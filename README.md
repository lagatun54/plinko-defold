# Кастомизация Plinko

Два параметра: **число корзин** и **веса** (куда чаще падают шары).

Оба задаются в [`game.project`](game.project), секция `[plinko]`:

```ini
[plinko]
slot_count = 10
slot_weights = 0, 0, 0, 5, 65, 30, 0, 0, 0, 0
```

- `slot_count` — сколько корзин (целое от 2 до 32).
- `slot_weights` — веса слева направо через запятую. Длина списка должна быть равна `slot_count`.
- `0` — в эту корзину шар не целится. Чем больше число, тем чаще попадание.

Пример выше: почти все шары идут в 5-ю корзину (65), меньше в 6-ю (30) и 4-ю (5).

Очки за корзину — в [`plinko/config/config.lua`](plinko/config/config.lua), поле `SLOT_POINTS`. Длина массива должна совпадать с `slot_count`.

После смены `slot_count` нужен полный рестарт. Старый сейв сессии может не подняться.
